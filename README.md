## 🇬🇧 English Version

### About This Project
This repository contains the validated codebase for `Ohmyfood`, a mobile-first startup web application designed to list gourmet restaurant menus and interactive ordering features. Completed as part of my front-end training, the project focuses on advanced styling architectures, fluid mobile-first design, and rich CSS animations.

### What I Did
* **Mobile-First Development:** Engineered the complete responsive interface starting from mobile viewports up to desktop breakpoints, adhering strictly to Figma design specs and layout guidelines.
* **Scalable SASS Architecture:** Implemented a modular SASS structure leveraging the **7-1 architectural convention** (partials, variables, mixins, components, and layouts) for clean, maintainable, and scalable stylesheets.
* **Advanced CSS Animations & Keyframes:** Created custom loading spinners, smooth button transitions, and staggered card appearance animations using complex keyframe sequences and calculated SASS loop delays for a polished user experience.
* **Version Control & Collaboration:** Managed the complete development workflow using Git and GitHub, ensuring clean commit histories and structured feature branches.

### Skills & Tools Used
* **SASS (SCSS):** Variables, nesting, mixins, custom loops, and the 7-1 file organization pattern.
* **CSS3 Animations:** Keyframes, transition delays, cubic-bezier easing, and dynamic state interactions.
* **Mobile-First Methodology:** Responsive layout scaling from mobile screens to desktop layouts.
* **Figma & VS Code:** Design inspection, prototyping reference, and source code development.

## 🇫🇷 Version Française

### À propos de ce projet
Ce dépôt contient le code validé du projet `Ohmyfood`, une application web mobile-first permettant de découvrir des menus de restaurants gastronomiques et de composer des paniers interactifs. Réalisé dans le cadre de ma formation, ce projet met l'accent sur une architecture de style avancée, le design mobile-first et des animations CSS fluides.

### Ce que j'ai fait
* **Approche Mobile-First :** Conception et intégration de l'interface responsive en partant des écrans mobiles jusqu'aux résolutions desktop, dans le strict respect des maquettes Figma.
* **Architecture SASS Structurée :** Mise en place d'une organisation SASS rigoureuse inspirée de la **convention 7-1** (partials, variables, mixins, composants et layouts) pour garantir un code modulaire, propre et maintenable.
* **Animations CSS & Keyframes Avancées :** Création d'indicateurs de chargement (spinners), de transitions fluides sur les boutons et d'apparitions échelonnées (staggered animations) de cartes grâce à des boucles SASS calculées et des keyframes personnalisées.
* **Gestion de Version :** Utilisation de Git et GitHub pour le suivi du projet, assurant un historique de commits propre et un workflow de développement structuré.

### Compétences et Outils Utilisés
* **SASS (SCSS) :** Variables, imbrications, mixins, boucles programmatiques et respect de l'architecture 7-1.
* **Animations CSS3 :** Keyframes, délais de transition, courbes d'accélération (cubic-bezier) et micro-interactions.
* **Méthodologie Mobile-First :** Conception adaptative du mobile vers le desktop.
* **Figma & VS Code :** Analyse des maquettes de design et environnement de développement front-end.
